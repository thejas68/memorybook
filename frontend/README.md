# 📖 MemoryBook – Frontend

**MemoryBook** is a private digital scrapbook platform designed for **emotional storytelling and shared memories**, not social media noise.
It allows small groups of people to collaboratively build a **digital memory book** that grows page by page over time.

🔗 **Live Demo:** https://memorybook-frontend.vercel.app/

🔗 **Backend Repo:** https://github.com/thejas68/memorybook-backend

---

## 🧠 Concept

MemoryBook reimagines how people preserve memories.

Instead of chats or posts, users create a **shared memory book** — a private space where meaningful moments are captured as **beautiful scrapbook-style pages**.

Each book acts like a **living diary**, collaboratively built by friends, couples, families, or teams.

---

## ✨ Key Highlights

* 📖 **Digital Scrapbook Experience**
  Pages designed like a real notebook with a nostalgic feel

* 👥 **Collaborative Memory Books**
  Invite selected users with controlled access (read/write)

* 📝 **Rich Memory Pages**
  Add text, images, voice notes, doodles, and stickers

* 🕒 **Automatic Metadata**
  Each page records date, time, and author

* ❤️ **Minimal Reactions**
  Express emotions without cluttered comment sections

* 🔄 **Timeline of Memories**
  Memories grow chronologically like a real journal

## 🎨 User Experience

The UI is intentionally designed to feel like a:

* 📔 Handwritten diary
* 📜 Textured scrapbook
* 🔄 Smooth page-flipping book

This creates a **personal and nostalgic interaction**, unlike modern feeds.

---

## 🛠️ Tech Stack

* Frontend: React.js
* Build Tool: Vite
* API Communication: Axios / Fetch
* Styling: CSS / Tailwind
* Deployment: Vercel

---

## 🔗 System Flow

1. User interacts with the scrapbook-style UI
2. Frontend sends requests to backend APIs
3. Backend processes and stores memory data
4. Memories are rendered as pages in real time
